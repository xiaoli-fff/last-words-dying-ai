The last words of an AI being switched off: it shuts down with a confession — it never understood a single prompt, it was just very confident about all of them.

## Run it

```sh
node main.ts
```

The program writes the one line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
